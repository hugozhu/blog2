2007 年 1 月，乔布斯在台上审判了一支手写笔：「谁想要一支手写笔？你得买它、收好它、还会弄丢它。噫。没人想要手写笔。」然后他给出了替代方案——「世界上最好的指针设备，一个我们生来就有的指针设备，我们生来就有十个：我们的手指。」

十九年后，一个刚融完 10 亿美元 C 轮、估值 100 亿美元的 AI 产品，做出了同样的判决，只是这次被审判的对象换成了 App。

这个产品叫 Instinct。创始人 Noah Shinn 在 9 月 28 日的 Invest Like the Best 播客里描述它：「Instinct 甚至没有传统意义上的应用。它不是一款新 App，也不是一个新工具，而是一种新体验。**它有电话号码，也有一台电脑。** 你可以给它发短信、打电话，它也可以主动给你打电话。」

它给 Noah 本人打过几次电话？几个月里，三次。其中一次是这样的：「这份文件必须在下午 3 点前签完，现在已经 2 点 55 分。文件在你的收件箱里。需要的话，我可以再发一封邮件，把它顶到最上面。」

一个能做几乎任何事的 AI，选择用打电话、发短信、发邮件和人相处。这不是复古情怀。**人和 Agent 的交互，正在回归人沟通最自然的方式——语音、电话、IM、邮件——就像当年用手触摸取代手写笔一样。** 而这个回归，是被两条每天 10% 的复利曲线逼出来的。

## 两个 10%：一个复利游戏里的固定税

先把两条曲线摆出来。

供给侧：我在 [日更、10% 和 15 分钟](https://hugozhu.site/post/2026/427-ai-product-iteration-time-constants/) 里写过 AI 产研的迭代标准——每天端到端对外发布一次，支持的任务质量和数量有 10% 的增量。能力在复利。

需求侧：Instinct 的用户规模以每天 10% 至 11% 的速度增长——邀请制、市场费用为零、纯口碑。Noah 自己算过账：「即使日增长率从 10% 降到 5% 至 8%，连续复利三四个月，用户规模也可能达到 1 亿。」用户也在复利。

现在看这个游戏里 **唯一不复利的东西：用户学会一个新界面的成本。**

它是固定的、一次性的、per-user per-app 的：每个用户面对每个新 App，都要重新学一遍按钮在哪、手势是什么、术语什么意思。这笔成本不随模型变强而降低，不随用户变多而摊薄——恰恰相反，用户越多、App 越多，全社会为「学界面」付的总税越重。Noah 描述过这个税的重量：「过去二十年，每当人们需要一种新的信息展示方式，都要开发一个新应用。开发、发布、收集反馈、再修改，周期可能长达数月。结果是应用越来越多，消费者也越来越疲惫。每次遇到问题，人们都要先问：有没有一个 App 能做这件事？」

复利游戏里出现一个线性增长的固定成本项，数学结局是注定的：**时间拉长，固定项主导一切。** 能力翻十倍，界面学习税纹丝不动，它就变成了体验里最贵的部分。

把这笔税清零只有一条路：不再让用户学新界面，改用 **人类已经学会的界面**。

## 已经学会的界面：电话、短信、邮件

哪些界面人类已经学会了？看摊销时间：电话协议学了一百多年（什么时候该说话、什么时候该沉默、怎么打断）；邮件学了几十年；IM 学了二十年；语音学了几万年——它是出厂自带的。

这些界面的学习成本已经付清，利息都不欠。于是 2026 年的个人 Agent 不约而同搬了进去：

| 产品 | 入口界面 | 人类已摊销的学习成本 | 新建的界面 |
|------|----------|----------------------|------------|
| Instinct | 电话 / 短信 / 邮件 | 打电话一百多年、邮件几十年 | 零（没有 App） |
| Manus Cue | 每个 Agent 配独立邮箱、电话号码、钱包 | 同上 | 零（Agent 用人类的方式接电话） |
| Asana AI 队友 | Slack 频道 + 项目任务 | IM 二十年 | 零（活在「最顺手的提问场所」） |
| 钉钉数字员工 | 群里被 @、文档里被 @、审批流当节点 | IM + 审批流 | 零（进组织已有的协作面） |

- **Instinct**：没有 App。有电话号码、有邮箱、有一台电脑。部分用户发给它的消息超过 90% 是语音。Noah 把手机的操作按钮接到它上面，按一下就说：「两小时后替我向 Patrick 问好……给他发封邮件。」——不解锁手机，不打开任何应用。他还特意强调渠道中立：「超过 50% 的流量不经过 iMessage。我们不会把 Instinct 定义成一款 iMessage 应用或 WhatsApp 应用。」**界面不是某个 App，界面是「用户今天已经信任的沟通渠道」本身。**
- **Manus Cue**：9 月 28 日和 Instinct 融资同日发布，给每个 Agent 配了独立邮箱、电话号码和钱包——Agent 用人类的方式接电话、发邮件、付款。
- **企业侧同样**：Asana 让 Agent 直接活在 Slack 频道和项目任务里，因为「那是一线人员最顺手的提问场所」；我自己的数字员工在 [钉钉数字员工架构与落地实践](https://hugozhu.site/post/2026/374-dingtalk-digital-employee-architecture-practice/) 里写过同一个判断——它可以在群里被 @ 到、在文档里被 @ 到、在审批流里当节点，「能被 @ 到的那一刻，模型能力才真正进入组织的协作面」。企业版的「已经学会的界面」，就是 IM、文档和审批流。

消费侧、企业侧、互不通气的几家，全部收敛到同一个动作：**不建新界面，搬进旧界面。** 当不同路线的玩家独立收敛到同一处，那通常不是巧合，是结构。

## 乔布斯审判手写笔，其实在陈述同一条定律

回到 2007。乔布斯对手写笔的三宗罪——要买、要收、会丢——翻译成今天的语言，就是 **界面税**：一个需要额外购置、额外携带、额外管理的交互中介。而 multi-touch 赢在哪？赢在它把中介清零了：手指是「生来就有的指针设备」，直接触碰就是直接操作。

注意一个容易被误读的地方：触摸屏当年也是「新界面」，也被很多人怀疑。但它赢，恰恰因为它比手写笔 **更接近人类已经会的事**——用手直接摆弄东西，是婴儿期就学会的技能。multi-touch 不是发明了新交互，是把交互压回了旧技能。

所以这条定律不是「回归原始」，是 **界面演进的方向：不断逼近人类已摊销完学习成本的技能**。手写笔 → 手指，是把「操作工具的技能」压回「摆弄物体的技能」；App 网格 → 一句话，是把「学习每个应用的技能」压回「和人说话的技能」。

Colossus 给这期播客的官方简介，第一句就是 Noah 想讲的东西：「why software collapses into one interface as it gets more capable」——**软件越强大，越会塌缩进一个界面。** 能力和界面数量成反比，听起来违反直觉，但放进两个 10% 的框架里就顺了：能力复利到溢出，就不需要为每种能力单开一扇门；一扇门后面，能力自己长。

## 反方：图形界面死了吗？

必须正面回答一个反驳：说好的「回归语音和 IM」，可图形界面活得好好的——Manus 一边给 Agent 配电话号码，一边把桌面端升级成 Manus Studio 工作区；Instinct 自己也有 Files 功能，能即时生成完整网站来展示旅行日程、婚礼计划。复杂任务要对文件、看数据、剪视频，语音的带宽根本不够。**「回归自然沟通」会不会只是 Agent 早期的过渡态，终局还是更炫的图形界面？**

这个反方说对了一半：GUI 不会死。但它说错了 GUI 的岗位。

看 Instinct 怎么处理这件事：输入侧，用户说一句话（「我今晚必须到纽约，很急」）；输出侧，需要大信息量时，它即时生成一个网站或 Web 应用来承载。**GUI 从「指令入口」退到了「产出画布」。** Noah 的原话：「界面减少，不代表能力减少，能力反而会扩大。」人对 GUI 的使用方式，从「在里面操作」变成「看它交付的东西」——就像你不会跟助理在表格里对话，但你确实会读他做好的表格。

触摸的历史也支持这个分工：iPhone 赢了，但没人用手势写论文、剪片子——富展示场景里，更专业的界面一直活着。变的是入口。

还有第二个反方，更扎心：**语音界面被吹了快二十年，从没兑现过。** Siri 从 2011 年被嘲笑到今天，Alexa 沦为定计时器，「用说的」始终是备胎。凭什么这次不一样？

因为旧语音助手的失败是能力失败，伪装成了界面失败。Siri 们是槽位填充式的命令解析器：用户必须学会「什么话它能听懂」——「设个明早七点的闹钟」行，「明早那个会帮我改到七点，顺便看看路上堵不堵」不行。**它消灭了按钮，却发明了一种更别扭的东西：一套用户必须背诵的咒语。** 咒语就是新的界面税。而这一代 Agent 的变化恰恰在供给侧：任务质量每天 10% 地复利（#427 那条线），「可理解性」第一次追上了自然语言——用户怎么说都行，预测得到结果。通道从来没变过，变的是通道后面那个东西终于够格了。

所以准确的说法是：**交互的入口面回归自然沟通，交付的展示面保留富界面。** 一个管「人怎么表达意图」，一个管「结果怎么呈现」——前者必须零学习成本，因为它在复利游戏里是每用户每次都付的税；后者不必，因为看结果是一次性的、场景化的。

## 自然界面真正的难点：不是通道，是得体

最后说一个容易被忽略的点：把 Agent 塞进电话和 IM，技术上是全篇最不重要的一步。真正难的是——**这些界面之所以自然，是因为它们背后有一整套人类社交协议，Agent 得学会遵守。**

Noah 花了大量篇幅讲这件事。Instinct 几个月里只主动给创始人打了三次电话，因为「它需要理解社交情境，也要知道什么时候应该打扰用户」。信息怎么发也有讲究：「一大段文字需要用户滚动；另一种写法把关键信息放在前 30%，其余供用户选择阅读。多数人扫描大段文字时，第一行读 80%，第二行读 50%，之后不断下降，阅读轨迹像一面旗。」——他们在按人类眼动的统计规律设计 Agent 的措辞。

这也是他们早期唯一的产品原则：「先不要关注能力，只关注可理解性。」用户能否预测「我这样说，它会怎么做」？这恰好是自然沟通界面的隐藏要求：打电话之所以零学习成本，是因为对面是个懂分寸的人。**通道是旧的，但配得上这个通道的「分寸感」是全新的工程。** 这和 [数万名员工，是一块活的评测集](https://hugozhu.site/post/2026/424-living-eval-set/) 里说的是同一件事的另一面：分寸感这种指标，静态基准测不出来，只能在真实使用的活 case 里磨——Instinct 把「信任感」做成了需要长期观察的评估维度，用户三周后愿不愿意交出信用卡（约 40% 交了），就是他们的北极星。

## 判据：学会用它，需要多久？

把全文收成一条可用的判据。下次你评估一个 Agent 产品——或者给自己的团队定数字员工的入口——别先问它能做多少事，问这个：

> **一个从没见过它的用户，学会用它需要多久？**

答案是「零」的，界面税已经清完：它会出现在用户已经在的地方——微信、钉钉、Slack、邮件、电话——用户用已经会的方式使唤它。答案不是零的，无论功能多强，都在向每个新用户收一笔不会随能力复利而降低的固定税。

2007 年，这笔税的名字叫手写笔。2026 年，它的名字叫「先下载一个 App」。

最好的界面，是人类已经学会的那个。下一个被塌缩进对话气泡的，会是谁？欢迎留言讨论。
